## Projects

### 1. UAV & AI Tree Canopy Health Analysis — Greenlawn Cemetery

Collected high-resolution multispectral UAV imagery and generated orthomosaics for spatial analysis of an urban cemetery. Applied AI-based image segmentation to delineate individual tree canopies, then produced NDVI rasters and a canopy height model to assess per-tree vegetation health. Extracted tree-level metrics to support urban tree inventory and management planning.

**Tools Used:** ArcGIS Pro · UAV/Multispectral Imagery · AI Segmentation · NDVI · Canopy Height Modeling

### 2. Community Preservation Act StoryMap
**City of Salem — Department of Planning and Community Development**

Geolocated and mapped 100+ projects funded through the Community Preservation Act using ArcGIS Pro. Built an interactive StoryMap integrating spatial data, project descriptions, and site images to improve public accessibility and engagement. Created a comprehensive, queryable spatial dataset with categorized thematic maps by project type.

**Tools Used:** ArcGIS Pro · ArcGIS Online · ArcGIS StoryMaps · Excel
